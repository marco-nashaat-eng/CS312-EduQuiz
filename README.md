# EduQuiz - CS312 Windows Forms & GDI+ Project

A quiz management system built with C# Windows Forms (.NET Framework 4.8).

## How to run
1. Open `QuizSystem.sln` in Visual Studio.
2. Press F5.

## Demo accounts (password for all: 1234)
- Admin: `admin`
- Teacher: `teacher`
- Student: `ahmed`

## Component 1 - Windows Forms Controls & Event Handling
Login, role dashboards, quiz taking, question and class management, search, sorting,
keyboard shortcuts, custom controls (ModernButton, ModernTextBox, ChipSelector...).

## Component 2 - GDI+ / Graphics / Visualization
Custom-painted UI, score ring cards, animated column chart with hover tooltips
(Results -> Analytics, or Ctrl+G), donut chart, PNG export, and a profile photo editor
(click your avatar: drag, zoom and rotate a picture inside a round window).

## See the charts
Log in as a student (`ahmed`), take a quiz, then log in as `teacher` -> Results -> Analytics.
